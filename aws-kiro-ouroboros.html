CH2 — HONESTY
CODE CHECK · KiroAgentAdapter.capabilities

못 하는 것도, 코드로 선언합니다

RuntimeCapabilities(
  skill_dispatch    = True,   # ooo <skill>이 Kiro 안에서 그대로 동작
  targeted_resume  = False,  # headless가 session id를 stdout에 안 내보냄
  structured_output = False,  # JSONL 스트림 대신 plain text
)
  • 스스로 얻을 수 없는 id는 할 수 있다고 광고하지 않습니다.
  • 호출자는 backend 이름이 아니라 capability로 분기 — 플래그만 뒤집으면 끝.

CH3 — THE OUTPUT
KIRO × OUROBOROS · WHAT COMES OUT

손에 남는 건
네 가지입니다

  • 통과한 코드 — orchestrator 채점 완료분만.
  • seed_<id>.yaml — 같은 계약, Kiro에 안 잠김.
  • Event Ledger — ~/.ouroboros/ouroboros.db
  • AC Tree · Kanban — 실시간 진행 현황.
이 화면들은 Kiro를 모릅니다. 장부만 읽습니다.
CH3 — INSTALL
INSTALL · TWO COMMANDS

설치는 두 줄, 나머지는 setup이 합니다

$ pipx install 'ouroboros-ai[mcp]'  # 또는: uv tool install
$ ouroboros setup --runtime kiro

# 이후, 평소처럼:
$ kiro-cli chat
> ooo interview "I want to build a todo list CLI"
  • ~/.kiro/settings/mcp.json에 MCP 서버 등록 — 실패 시 전부 원복하는 트랜잭션.
  • 선행 조건: Kiro CLI 2.2.0+ 로그인 · Python 3.12+.
docs/runtime-guides/kiro.md · 한국어 가이드: kiro.ko.md
